-   设置ssh远程无密码登陆

    电脑终端执行

    ```bash
    # 生成 ED25519 密钥（更安全、更快）
    ssh-keygen -t ed25519 -C "jetson-ssh"
    ```

    

    

    -   提示保存路径：直接回车（默认 `~/.ssh/id_ed25519`）
    -   提示输入密码（passphrase）：**直接回车两次**（留空才能完全免密）

    生成后会得到两个文件：

    -   `~/.ssh/id_ed25519`：私钥（本地保管，**绝不泄露**）

    -   `~/.ssh/id_ed25519.pub`：公钥（传到 Jetson）

        

        linux:

        ```bash
        # 替换为你的 Jetson 用户名和 IP
        ssh-copy-id username@jetson_ip
        ```

        

        window

        ```bash
        # 替换为你的 Jetson 用户名和 IP
        cat ~/.ssh/id_ed25519.pub | ssh username@jetson_ip "mkdir -p ~/.ssh && chmod 700 ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys"
        ```

        

        vscode请增加配置

        添加

        ```bash
        Host 192.168.5.27
          HostName 192.168.5.27
          User nvidia
          IdentityFile C:\Users\cwx\.ssh\id_ed25519
        ```
